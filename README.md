# pedrodaguer.github.io

Portfólio pessoal e profissional de Pedro d'Ávila Daguer.
Desenvolvedor backend, RPA e web.

Site estático (HTML, CSS e JavaScript), sem build. Publicado com GitHub Pages.

## Rodar localmente

```bash
python -m http.server 8787
# abrir http://127.0.0.1:8787
```

## Estrutura

- `index.html` — página única
- `css/style.css` — estilos e design system
- `js/app.js` — interações (canvas, reveals, formulário)
